# HITMA · 航天火箭发射与返回 · 备赛知识库

> 哈尔滨工业大学航模协会（HITMA）
> 赛事：中国大学生飞行器设计创新大赛（CUADC）2026
> 赛项：**航天火箭发射与返回**

这个仓库不写飞行代码，只放**比赛本身**：规则、评分、检查单、备赛计划
（`scoring/` 里的图由 `tools/score_chart.py` 按规则公式生成）。
所有规则条目均来自 `rules/CUADC-2026-rules.pdf`（官方公开版，第 42–45 页），
标注「推导」的是我们根据规则算出来、规则原文没有直接写的内容。

## 一句话说清赛项

用一发**固体发动机**模型火箭，把一架**可控无动力固定翼飞行器**（翼展 ≥ 300 mm）
和一枚**电子高度计**送上天，在接近 **50 m** 的高度把两者**同时**弹出；
火箭靠**降落伞**回收，飞行器**滑翔**回直径 40 m 的回收圈并落在靶心附近；
**比高度准、比落点准、比留空久**。

## 关键数字

| 项目 | 要求 | 出处 |
|---|---|---|
| 火箭总质量 | ≤ 500 g | 规则 2.1 |
| 发动机 | 仅固体，单发 ≤ Φ18 × 75 mm，外壳禁金属/碳纤/玻纤 | 规则 2.1 |
| 起飞方式 | 竖直起飞，起飞锥角 ≤ 90° | 规则 2.1 |
| 飞行器翼展 | ≥ 300 mm，可控无动力固定翼 | 规则 2.2 |
| 分离高度目标 | 50 m（偏差按 3 分/米扣） | 规则 6.1.2 |
| 回收区 | 直径 40 m 圆形，中心为靶心 | 规则 3.1.3 |
| 单轮比赛时间 | 入场 90 s + 比赛 5 min | 规则 5.5 |
| 轮次 | 两轮，取较好一轮 | 规则 6.2 |

## 成绩公式（速览）

```
单轮成绩 S = S发射 + S高度 + S载荷 + S箭体 + S留空

S发射 = 50（发射成功） / 0（失败，比赛终止）
S高度 = 100 − |H − 50| × 3        H 为高度计测得最高点
S载荷 = 80 − L × 4                L 为飞行器到靶心距离（≥ 0.1 m）
S箭体 = 20（伞降进回收区） / 0
S留空 = (T − 10) × 10             T 为飞行器留空秒数，T < 10 则归零
```

**注意**：留空分与载荷回收分是绑定的——`S载荷 = 0` 时留空分一并归零。
详见 [scoring/README.md](scoring/README.md)。

## 参赛基本规则（防踩坑）

- 每个参赛单位**最多 2 个机组**，每机组**组长 1 人 + 组员 ≤ 3 人**（规则 4.1、4.2）
- 指导教师**不得入场**，也不得以任何形式指挥比赛（规则 5.2）
- 进场后**必须戴安全帽**（规则 5.4、7.4.1）
- 每轮**只允许一次正式发射**，火箭离架即算（规则 5.7）
- 提前抢发、空中解体、载荷外露都会被判 0 分或取消资格，详见判罚表
