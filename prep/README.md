# 备赛计划

按"先保 250 分基础盘，再冲留空分"的思路排优先级（见 [../scoring/README.md](../scoring/README.md)）。

## 分系统与交付物

| 分系统 | 交付物 | 关键指标 | 依赖 |
|---|---|---|---|
| 总体 | 质量预算表、气动外形 | 总质量 ≤ 500 g | — |
| 箭体结构 | 图纸、加工件、装配工艺 | 出架顺利、蒙皮不裂 | 总体 |
| 分离机构 | 机构件 + 地面测试台 | 高度计与飞机**同步**分离 | 结构、电气 |
| 伞降回收 | 伞、伞舱、开伞逻辑 | 每个可分离段各一顶伞 | 结构 |
| 飞行器 | 折叠翼 + 配平 + 遥控链路 | 翼展 ≥ 300 mm，可控，留空 ≥ 10 s | 总体 |
| 电气 | 供电、硬排、点火、高度计固定 | 晃动不断电，舵机无延迟 | 结构 |
| 外场 | 发射架、检查单、应急预案 | 5 min 内完成发射 | 全部 |

## 里程碑（相对赛期，T = 比赛日）

| 节点 | 目标 | 出口条件 |
|---|---|---|
| T−8 周 | 方案冻结 | 质量预算、外形、分离方式定稿 |
| T−6 周 | 结构出图 + 加工 | 装配完成，静置不歪 |
| T−5 周 | 分离机构地面验证 | 连续 10 次同步分离，无卡滞 |
| T−4 周 | 飞行器首飞 | 抛飞正常，留空 ≥ 30 s |
| T−3 周 | 全箭总装 + 质量审核模拟 | 总质量、翼展、外露全部合规 |
| T−2 周 | 外场实飞（低空分离） | 分离高度可调、伞降正常 |
| T−1 周 | 全流程演练 | 5 min 内完成，检查单零遗漏 |
| T 周 | 比赛 | 两轮，取较好一轮 |

> 每个节点都要有"不合格怎么办"的预案。T−2 周还没做到低空分离，就要启动降级方案
> （例如放弃姿态控制，只保发射 + 伞降 + 滑翔）。

## 机组分工（4 人上限）

| 角色 | 职责 | 关键动作 |
|---|---|---|
| 组长 | 指挥、对裁判沟通 | 申请发射、报数、喊口令 |
| 发射操作 | 上架、点火 | 上电、锁紧硬排、请求发射 |
| 飞手 | 遥控飞行器 | 分离后接管滑翔 |
| 回收/记录 | 计时、回收、记录 | 记录分离高度、落点、留空时间 |

规则要求机组全程在号位内（7.4.6），4 个人就是全部人手，不能指望场外支援。

## 地面测试爬坡

不要跳级，每一级通过再上一级：

```
1. 单板测试      舵机、供电、链路，不装箭
2. 总装静置      外观、质量、重心
3. 分离机构台架  连续 10 次同步分离
4. 整箭地面测试   上架 → 出架 → 弹出（不带火工品）
5. 低空实飞      低分离高度，验证伞降与分离时序
6. 全流程演练     带计时、带检查单、带裁判式申请
```

## 风险台账

| 风险 | 影响 | 缓解 |
|---|---|---|
| 总质量超 500 g | 取消资格 | 每周称重，留 30 g 余量 |
| 分离不同步 | 高度分 + 回收分归零 | 单一驱动源同时释放两个锁 |
| 飞行器出圈 | 载荷分 + 全部留空分清零 | 飞手以"进圈"为第一目标 |
| 留空 < 10 s | 双重归零 | 留空 ≥ 30 s 才算安全余量 |
| 空中解体 | 整轮 0 分 | 蒙皮、伞绳、分离冲击都要做地面验证 |
| 现场准备超时 | 该轮无法发射 | 全流程演练压到 3 min 以内 |
| 侧风大 | 起飞锥角超标 | 侧风 > 5 m/s 时重算弹道或申请延时 |

## 每周节奏

- **周一**：分系统对齐，更新本页里程碑状态
- **周三**：地面测试/台架试验，记录数据
- **周五**：外场或风洞/抛飞，回收检查单
- **周日**：复盘，更新 [../checklist/README.md](../checklist/README.md) 里发现的新坑
