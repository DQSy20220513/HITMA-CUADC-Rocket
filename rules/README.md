# CUADC 2026 · 航天火箭发射与返回 · 规则梳理

原文：`CUADC-2026-rules.pdf`（第 42–45 页）。本文是逐条摘录 + 工程解读，
**遇到歧义以原文为准**。标注「解读」的是我们的理解，不是规则原文。

## 1. 任务简述

> 以航天火箭可控发射与定点返回任务为背景，考察航天火箭的总体设计、控制系统设计、
> 着陆伞设计、飞行器折叠结构与分离机构设计等综合能力。

任务：发射以固体发动机为动力、携带**可控无动力固定翼飞行器**的小型火箭，
使**任务载荷与火箭箭体在指定高度分离**，安全回收火箭箭体，控制飞行器滑翔并
着陆至指定区域。**以分离高度和着陆位置准确取胜。**

## 2. 技术要求

| 条款 | 原文要点 | 工程含义（解读） |
|---|---|---|
| 2.1 质量 | 火箭总质量 **≤ 500 g** | 含全部载荷；这是最硬的约束，直接压死结构方案 |
| 2.1 直径 | 箭体直径不限 | 可自行权衡长径比与阻力 |
| 2.1 动力 | 仅固体发动机；单发 **≤ Φ18×75 mm**；外壳禁金属/碳纤/玻纤 | 只能用成品模型发动机（如 C/D 级），推力与总冲被锁死 |
| 2.1 起飞 | 竖直起飞，**起飞锥角 ≤ 90°** | 锥角 = 发射点-最高点连线与地面法线夹角 **×2**，即弹道偏离竖直不超过 45° |
| 2.2 载荷一 | 专用型号电子高度计，**不得与箭体有任何电或信号连接**，自行准备 | 独立供电、独立记录；任何连线都是取消资格 |
| 2.2 载荷二 | 可控无动力固定翼，**翼展 ≥ 300 mm** | 且必须能折叠/拆装进箭体 |
| 2.2 安装 | 高度计与飞行器**均装在箭体内**，飞行器任何部分**不得外露** | 分离前外露 → 该轮 0 分（7.4.5） |
| 2.3 分离 | 发射后与地面无物理连接；**高度计与飞行器必须同时分离** | 同时 = 同一动作/同一时刻，不能先弹飞机再抛高度计 |
| 2.3 判定 | 分离至落地前两者无物理连接即为成功分离 | 用伞绳拴在一起不算分离 |
| 2.4 回收 | 箭体**伞降**回收；伞与伞绳不限 | 多部件分离时**每个部件单独一顶伞** |
| 2.4 着陆 | 箭体与飞行器着陆后**均不得自主移动** | 落地后滑跑/被风吹走会判未回收 |
| 2.5 定义 | 总质量 = 完整系统 + 全部载荷；空载质量 = 不含任务载荷（含动力） | 审核只称空载质量，但 2.1 的 500 g 是总质量 |
| 2.6 标识 | 箭体醒目位置标识参赛单位标志及名称 | 赛前就被检查 |

> **解读——起飞锥角**：规则定义为「连线与地面法线夹角的两倍」，
> 所以 90° 上限等价于弹道最高点相对发射点的水平偏移 / 高度 ≤ tan(45°) = 1。
> 换句话说：飞到 50 m 高时，水平偏移不能超过 50 m。无风时这不是问题，
> 侧风超过约 5 m/s 就要认真算。

## 3. 场地设置

| 条款 | 内容 |
|---|---|
| 3.1 | 400 m 标准体育场或等同面积；土质/草地/硬质地面 |
| 3.1.1 | **准备区**：检录、审核、待飞 |
| 3.1.2 | **发射区**：若干号位，每号位 ≥ 5×5 m，间隔 ≥ 5 m；机组全程不得离开号位 |
| 3.1.3 | **回收区**：直径 **40 m** 圆形，中心为**靶心** |
| 3.2 | 安全区在场地一侧，观众在安全区内 |

## 4. 参赛选手

- 4.1 每个参赛单位**最多 2 个机组**，每机组**不超过 4 人**
- 4.2 每机组 = 组长 1 人 + 组员 ≤ 3 人

## 5. 竞赛方法（现场时序）

```
抽签定出场顺序
   │
   ▼
检录（按批次）
   │
   ▼
审核区：称空载质量 → 领取高度计
   │
   ▼
准备区：装配、自检
   │
   ▼
发射区：戴安全帽 → 入场 90 s → 开始计时（每轮 5 min）
   │
   ▼
向号位裁判申请发射 → 获准 → 发射
   │
   ▼
火箭离架 = 正式发射（每轮只有一次）
   │
   ▼
回收：箭体伞降 + 飞行器滑翔着陆
```

| 条款 | 内容 |
|---|---|
| 5.1 | 共**两轮**，电脑随机抽签定序 |
| 5.2 | **指导教师不得入场**或以任何形式指挥 |
| 5.3 | 完成**空载质量审核**后领取高度计，进准备区 |
| 5.4 | 进入发射区**必须戴安全帽** |
| 5.5 | 入场 **90 s**；入场时间到即开始计比赛时间；每轮 **5 min** |
| 5.6 | 准备完毕**向号位裁判申请**，获准后才能发射 |
| 5.7 | 火箭**离架即为正式发射**，每机组每轮**只允许一次** |

> **待确认**：2.2 写"高度计由参赛单位自行准备"，5.3 写"领取高度计"。
> 两种读法（自备 / 组委会发）会直接影响赛前准备清单，赛前务必找裁判确认。

## 6. 成绩评定

```
S = S发射 + S高度 + S载荷 + S箭体 + S留空
```

| 分项 | 满分 | 公式 | 条件 |
|---|---|---|---|
| S发射 | 50 | 成功 50 / 失败 0 | 正常点火、助推段稳定、锥角 ≤ 90°；失败则该轮终止 |
| S高度 | 100 | `100 − |H − 50| × 3` | H 用高度计测最高点，精确到分米；未分离或无高度计 → 0；< 0 记 0 |
| S载荷 | 80 | `80 − L × 4` | L 为飞行器到靶心距离；L < 0.1 m 记满分 80；< 0 记 0 |
| S箭体 | 20 | 成功 20 / 失败 0 | 箭体伞降进回收区；多头锥/多段以装高度计那段为准 |
| S留空 | 无上限 | `(T − 10) × 10` | T 为飞行器留空整秒数；T < 10 或 S载荷 = 0 → 0 |

- **计时**：火箭点火后移动开始计时，飞行器着陆静止停表；秒数舍去尾数
- **取优**：两轮取较高一轮
- **并列**：先比另一轮成绩，再比该轮对应火箭的**空载质量**（轻者列前）

## 7. 判罚

| 触发条件 | 后果 | 条款 |
|---|---|---|
| 飞行器飞行/着陆后零件脱落或解体 | S载荷 = 0 | 7.1.1 |
| 飞行器与箭体缠绕 | S载荷 = 0 | 7.1.2 |
| 飞行器未着陆至回收区 | S载荷 = 0 | 7.1.3 |
| 留空 < 10 s | S留空 = 0，S载荷 = 0 | 7.2.1 |
| 未经裁判允许触碰高度计和飞行器 | S高度 = 0，回收分 = 0 | 7.3.1 |
| 高度计与飞行器未同时分离 | S高度 = 0，回收分 = 0 | 7.3.2 |
| 进发射区未戴安全帽且警告无效 | **该轮 0 分** | 7.4.1 |
| 裁判口令前抢先发射 | **该轮 0 分** | 7.4.2 |
| 未正常点火 / 助推段姿态不稳 / 锥角 > 90° | **该轮 0 分** | 7.4.3 |
| 空中解体，或非伞降部件 | **该轮 0 分** | 7.4.4 |
| 分离前载荷任意外露 | **该轮 0 分** | 7.4.5 |
| 机组离开所在号位 | **该轮 0 分** | 7.4.6 |
| 使用未审核的火箭 / 载荷，或擅自改载荷 | **取消资格** | 7.5.1、7.5.2 |
| 高度计与箭体有电或信号连接 | **取消资格** | 7.5.3 |
| 修改高度计参数 | **取消资格** | 7.5.4 |
| 飞行器不具备可控性 | **取消资格** | 7.5.5 |

## 8. 从规则反推的设计输入

把上面条款翻译成设计指标，直接进设计评审：

| 设计输入 | 数值 | 来源 |
|---|---|---|
| 总质量预算 | ≤ 500 g（建议留 30 g 余量） | 2.1 |
| 发动机约束 | 外壳 ≤ Φ18 × 75 mm | 2.1 |
| 分离高度设定 | 50 m | 6.1.2 |
| 弹道偏摆 | 最高点水平偏移 ≤ 高度 | 2.1 |
| 飞行器翼展 | ≥ 300 mm，可折叠入箭体 | 2.2 |
| 舱内净空 | 须同时容纳高度计 + 折叠飞行器 | 2.2 |
| 分离机构 | 高度计与飞行器**同步**释放 | 2.3 |
| 伞降部件 | 每个可分离段各配一顶伞 | 2.4 |
| 着陆后静止 | 不得有动力/滑行 | 2.4 |
| 标识 | 单位标志 + 名称，醒目位置 | 2.6 |
