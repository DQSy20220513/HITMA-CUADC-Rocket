# 检查单

按顺序走，**全部打勾才能进入下一阶段**。任何一项不过，停下来排查。
本检查单来自队内实际外场流程（实验室 → 候场 → 赛场三级），
最后一节是按规则反推的合规检查。

## 一、实验室检查（出发前）

- [ ] 舵机安装位置、摇臂角度合适
- [ ] 电路板和硬排能正常供电；晃动火箭不断电；操作舵机无异常延迟
- [ ] 火箭整体不歪
- [ ] 尾翼安装不歪
- [ ] 各部分装配顺利（做成配套件，减少现场调整）
- [ ] 蒙皮完整无开裂
- [ ] 伞绳系紧、不打结
- [ ] 插电池、拨开关、放高度计都顺手（不别扭、不需要硬塞）
- [ ] 各种电池电量充足
- [ ] 飞行器抛飞调试正常
- [ ] 火箭满载后出架顺利
- [ ] **全流程地面测试**（上架 → 出架 → 弹出）

## 二、候场检查

- [ ] 完整火箭各舱段装配紧密、无晃动
- [ ] 飞行器能完全展开
- [ ] 接收机正常，控制正常
- [ ] 伞与火箭连接紧，伞绳不乱
- [ ] 发射架螺丝不松，调好的结构无松动
- [ ] **全流程地面测试**（上架 → 出架 → 弹出）

## 三、赛场检查（上架前）

- [ ] 硬排开关处于**锁紧**状态
- [ ] 伞绳不暴露
- [ ] 点火头不松动
- [ ] 蒙皮无开裂
- [ ] 看清中断线位置再上架
- [ ] 上架后尾翼不靠近发射架竖杆
- [ ] 上电前**再次**确认硬排开关锁紧
- [ ] 保险解除显示红灯，人员远离后，点火人员再请求发射

## 四、规则合规检查（按 CUADC 2026 规则反推）

赛前和审核前各做一遍：

| 检查项 | 要求 | 条款 |
|---|---|---|
| 总质量 | ≤ 500 g（含高度计 + 飞行器） | 2.1 |
| 发动机 | 固体，单发 ≤ Φ18 × 75 mm，外壳非金属/碳纤/玻纤 | 2.1 |
| 飞行器翼展 | ≥ 300 mm | 2.2 |
| 载荷外露 | 分离前不得有任何部分露出箭体 | 2.2 / 7.4.5 |
| 高度计连线 | **无任何电或信号连接** | 2.2 / 7.5.3 |
| 同时分离 | 高度计与飞行器同一动作释放 | 2.3 / 7.3.2 |
| 伞降部件 | 每个可分离段各有一顶伞，无自由落体件 | 2.4 / 7.4.4 |
| 着陆静止 | 无动力、不自走 | 2.4 |
| 标识 | 醒目位置有单位标志与名称 | 2.6 |
| 安全帽 | 进发射区全员佩戴 | 5.4 / 7.4.1 |

## 五、检查项 → 判罚对照

让队员知道"漏检"值多少钱：

| 漏掉的检查 | 可能触发 | 代价 |
|---|---|---|
| 蒙皮开裂未发现 | 空中解体（7.4.4） | 整轮 0 分 |
| 伞绳外露 | 分离前载荷外露（7.4.5） | 整轮 0 分 |
| 高度计与飞机未同步 | 7.3.2 | 高度分 + 回收分归零 |
| 伞绳缠绕 | 7.1.2 | 载荷回收分归零 |
| 硬排未锁紧 | 上电解锁 / 误触发 | 失控或抢发（7.4.2）→ 整轮 0 分 |
| 未戴安全帽 | 7.4.1 | 警告无效则整轮 0 分 |
| 提前发射 | 7.4.2 | 整轮 0 分 |

## 使用建议

- 打印成 A4，现场用笔打勾，不要用手机
- 每条后面留一格写"谁检查"——责任到人
- 全流程地面测试是唯一能同时验证"上架/出架/弹出"的手段，别省
